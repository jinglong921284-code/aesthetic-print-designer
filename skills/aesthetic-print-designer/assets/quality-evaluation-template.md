### 直接淘汰

| 检查项 | 结果 | 证据/说明 |

| 近似复制、受保护标识、角色或可识别原参考构图 | 无 / 有 |  |

| 回位文件包含文字、模特、服装、边框、阴影或透视 | 无 / 有 / 不适用 |  |
| 未经验证却标注为无缝或生产文件 | 无 / 有 |  |
| 最终文件损坏、缺失或版本错误 | 无 / 有 / 不适用 |  |

任一项为“有”，结论直接为 `Fail`。

### 打样前必须关闭

| 检查项 | 结果 | 证据/说明 |

| 接缝、截断、白点、重叠或宽度跳变 | 无 / 有 / 待检查 |  |
| 方格、轨道、镜像菱形、风车、人脸或焦点重复 | 无 / 有 / 待检查 |  |
| 回位数据、Offset和3×3检查完整 | 是 / 否 / 不适用 |  |
| 定位/边框/工程印花的尺寸、方向、锚点及裁片约束完整 | 是 / 否 / 不适用 |  |
| 批准配色、颜色数量和画面肌理保持一致 | 是 / 否 / 待确认 |  |
| cm、像素、DPI、色彩模式、文件名和版本一致 | 是 / 否 / 待确认 |  |
| 会改变设计决策的面料或工艺风险已关闭 | 是 / 否 / 待确认 |  |

任一适用项为“有”“否”或“待确认”，不得进入打样，结论至少为 `Revise`。
