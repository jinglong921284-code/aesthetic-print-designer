# Print Systems

## Placement print

Define the artwork boundary, focal point, orientation, physical scale, garment zone, and distance from seams or closures. Require a clean artwork view separate from the mockup.

## All-over repeat

Define ground colour, motif roles, directionality, tile dimensions, spacing rhythm, and repeat geometry. Use half-drop or brick repeat only when it improves rhythm. Avoid obvious grids and repeated clusters.

## Four-way repeat

Use when nondirectional cutting efficiency matters. Balance motifs across rotations without creating pinwheels or mirrored faces. Require exact left/right and top/bottom continuity.

### Validation sequence

1. Export a clean flat candidate without garment, model, text, shadow, frame, or perspective.
2. Compare first/last columns and first/last rows as an edge-lock check, not as a complete seamlessness verdict.
3. Half-offset horizontally and vertically so the four original boundaries meet in the centre.
4. Inspect the central cross for clipped tips, width jumps, overlaps, pinholes, and direction changes.
5. Build a minimum 3 × 3 preview and inspect for grids, tracks, repeated islands, Y-shapes, diamonds, faces, or mirror symmetry.
6. Repair the central cross while protecting the outer safe zone.
7. Lock periodic edges, rerun the data check, inspect both diagnostics, and record the visual decision and evidence in the validation report.

Exact edge equality proves that boundary pixels are locked; it does not prove visual seamlessness. A repeat fails when the large-area preview shows a visible repeat block or a repair artifact. Do not issue the final pass label while the visual status is pending.

### Optional visual-editor handoff

Use any available image editor to create and repair visual content, not to certify production continuity. Keep repeat repair in the same-theme working context when the tool supports it. Upload the half-offset diagnostic as the edit target, change only the central cross, preserve the outer 20%-25% safe zone, and export the repaired flat artwork at the highest available resolution. When Lovart is available and selected, apply the canvas-continuity details in `references/lovart-workflow.md`.

## Border print

Define border depth, edge orientation, transition zone, corner behavior, and the relationship between border and field. State whether the border follows hem, cuff, scarf edge, or another construction line.

## Engineered or panel print

Design for named pattern pieces. State artwork registration, seam crossings, mirrored pieces, grain direction, bleed allowance, and placement tolerance. Coordinate final decisions with the garment construction workflow.

## Production distinction

An image-generation result is a concept until all of the following are verified: exact repeat, physical scale, resolution, colour mode and separations, print process, fabric behavior, bleed, registration, and supplier requirements. `Digital seamless repeat passed` does not mean `production artwork approved`.
